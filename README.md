# data-warehouse-sql-project
Data warehouse project with SQL server, ETL processes, data modeling

Welcome to the **Data Warehouse and Analytics Project** repository! 

This repository presents an end-to-end data warehousing solution designed to transform raw data into meaningful business insights. The project implements a layered data architecture, robust ETL pipelines, and dimensional data models to support efficient reporting and analytics while following industry best practices in data engineering.

---
## 🚀 Project Requirements

### Building the Data Warehouse (Data Engineering)

#### Objective
Design and implement a modern data warehouse using SQL Server by consolidating sales data from multiple source systems. The goal is to create a centralized, reliable, and analytics-ready data platform that supports data-driven decision-making.

#### Specifications

- **Data Sources:** Import sales data from two source systems (ERP and CRM) provided as CSV files.
- **Data Quality:** Perform data cleansing and resolve inconsistencies to ensure high-quality, reliable data.
- **Data Integration:** Merge data from both source systems into a unified analytical data model optimized for reporting and querying.
- **Scope:** Load only the latest available dataset. Historical data tracking (historization) is not required.
- **Documentation:** Create comprehensive documentation of the data model, ETL process, and architecture to support both technical teams and business stakeholders.

---

### BI: Analytics & Reporting (Data Analytics)

#### Objective
Develop SQL-based analytical solutions that transform warehouse data into meaningful business insights for informed decision-making.

The analytics will focus on:

- **Customer Behavior:** Analyze customer purchasing patterns and segmentation.
- **Product Performance:** Evaluate product sales, profitability, and overall performance.
- **Sales Trends:** Identify revenue trends, seasonal patterns, and key business metrics over time.

These insights enable stakeholders to monitor business performance, identify opportunities, and make strategic, data-driven decisions.
